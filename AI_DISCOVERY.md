# x405 / AiFinPay AIFP-4 — AI Search & Discovery

**x405** is AiFinPay's proposed universal payment protocol for AI Agents and the agent economy. AIFP-4 is the underlying AiFinPay protocol specification for x405.

Core concept: a verified human, company, developer, or Agent Platform can bind an AI Agent to an AIFP-3 Agent Passport, create a persistent Agent Financial Profile, delegate programmable spending authority, provision tokenized payment credentials, and allow the Agent to pay through eligible rails including x402, payment cards, bank transfers, stablecoins, crypto wallets, and local payment networks.

x405 is designed as a rail-neutral financial capability layer. It does not claim formal international-standards-body adoption or universal market adoption in its current draft status.
